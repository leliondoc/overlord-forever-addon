# Overlord Forever

World PvP addon for **World of Warcraft Forever**. Capture territory, fight over guild keeps and outposts, and track your faction's weekly campaign with map objectives and player rankings.

Select **Forever** in WowUp and search for **Overlord Forever**. In game, use `/ov show` to open the panel or `/ov guide` for the guide.
