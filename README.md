# Overlord Forever

Addon **World of Warcraft: Forever** pour la capture de zones sur les fronts du monde ouvert : synchronisation entre joueurs, carte, classement, domination hebdomadaire.

## Installation

**Recommandé :** installer via [CurseForge](https://www.curseforge.com/wow/addons/overlord-forever).

**Manuel :** placer le dossier `Overlord` dans `World of Warcraft\_classic_beta_\Interface\AddOns\`, puis `/reload` en jeu.

## Fronts

- **Hautes-terres d'Arathi** (`arathi`) : mêmes points de capture que Overlord Retail
- **Loch Modan** (`loch_modan`)
- **Durotar** (`durotar`)
- **Orneval / Ashenvale** (`ashenvale`)

Pas de Gilnéas, Arathi, ni Tarides du Sud (carte unique Forever, pas de scission Cataclysm).

## Fonctionnalités

- Capture de zones, contestation, prérequis, overlays carte/minimap.
- Sync canal de royaume, groupe/raid, communautés Battle.net, relais BNet cross-faction.
- Mines d'or, bois, renforts, barricades, domination hebdomadaire.
- Fortins de guilde et avant-postes.

## Commandes

Alias : `/ov` et `/overlord`. `/ov help` en jeu pour la liste.
