**Overlord Forever 1.2.3**

- Removed the "Only the enemy faction can assault ..." chat message. It repeated every 45 seconds for anyone standing in a guild keep or outpost square, even while just using the mailbox or passing through.
- Removed the "Enemy on another shard" popup. The game no longer allows inviting enemy players from another layer, so the popup only got in the way. The "Ally on another shard" popup still helps you group up with allied capturers.
